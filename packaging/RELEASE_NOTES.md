TodoBench 0.1.1 improves workspace diagnostics and the project documentation.

## What changed

- Workspace Diagnostics now explains what is checked, shows the workspace folder
  and loaded project/task counts, and clearly distinguishes a healthy workspace
  from one that has not been opened.
- Problems include expandable paths and messages. Duplicate-task recovery remains
  available, and the dialog explains how to refresh results after external edits.
- Copyright attribution is now © 2026 Aleksandr Oreshkin, including About TodoBench.
- The refreshed GitHub page and new website include real app screenshots, theme
  previews, platform downloads, and getting-started and interoperability guides.

Website: https://alex9001.github.io/TodoBench/

## Downloads and installation

Linux x86_64: AppImage or bundled portable tarball. Windows x64: portable ZIP or
per-user installer. macOS: separate Intel and Apple Silicon application ZIPs and
DMGs. Runtime libraries are bundled. Linux packages target Ubuntu 24.04 or
compatible newer systems.

Packages have no publisher certificates. macOS apps are ad-hoc signed, without
notarization. See the included installation guide for first-launch instructions.
Verify downloads against SHA256SUMS. Exact source, dependency source, third-party
notices, and build instructions accompany the binaries.

## Workspace compatibility

Existing workspaces require no migration. The workspace format remains schema
version 1. Automatic synchronization and merging remain outside this release.
