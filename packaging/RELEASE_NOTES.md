TodoBench 0.1.0 is a native Markdown workspace task manager for Linux, Windows,
and macOS, released under GPL-3.0-or-later.

- Public workspace v1 rules and independent edit/export fixtures.
- Byte-preserving notes, nested extensions, stale-save protection, and safer 7-Zip import.
- Consistent Lucide controls and a checklist launcher on every platform.
- General-purpose samples, recurrence, reminders, attachments, and customizable themes.

Choose the package for your OS and architecture. Check SHA256SUMS before installing.
Binaries are unsigned by a publisher; macOS apps have ad-hoc signatures. See
packaging.md for installation and build instructions. Exact source and dependency
source archives accompany the binaries. Workspaces need no bulk migration.
